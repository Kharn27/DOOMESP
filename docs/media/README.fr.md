# Médias de la documentation

[English version](README.md)

Les photos et les vidéos de ce dossier ont été capturées sur la JC3248W535
testée pendant le développement. Elles illustrent le port et ne constituent
pas des données de jeu nécessaires au firmware.

- `gameplay.jpg` montre le HUD actuel en jeu et les commandes tactiles.
- `gameplay-action.jpg` capture le jeu sous la palette de dégâts de DOOM.
- `main-menu.jpg` montre le menu original de DOOM avec l'interface tactile.
- `weapon-selector.jpg` et `cheat-selector.jpg` montrent les deux sélecteurs
  personnalisés et leurs illustrations extraites du WAD.
- `board-back.jpg` identifie le PCB testé et ses principaux composants.
- `audio-wiring.jpg` documente le branchement amplifié du haut-parleur employé
  pendant le développement.
- `gameplay-demo.mp4` montre une séquence de jeu prolongée avec l'interface
  portrait complète.
- `touch-controls.mp4` montre le lancement d'une partie, les commandes
  tactiles simultanées et le sélecteur d'armes alimenté par le WAD.

Elles sont séparées du code source distribué sous GPL-2.0. Les visuels, noms
et marques de DOOM restent la propriété de leurs détenteurs respectifs.
